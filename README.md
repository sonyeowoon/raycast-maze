# Raycast Maze

C와 MiniLibX를 사용해 2차원 격자 지도를 1인칭 시점으로 렌더링하는 그래픽 학습 프로젝트입니다. 화면의 각 세로 줄에 대응하는 광선을 추적하고, 벽까지의 거리를 화면상의 벽 높이로 변환합니다.

## 주요 구현

- DDA 알고리즘으로 광선과 격자 벽의 교차 위치 탐색
- 카메라 방향과 평면을 사용한 시야 계산
- 벽 렌더링, 텍스처 처리 및 플레이어 이동
- 지도 설정, 색상, 텍스처 경로, 시작 위치와 벽 경계 검증
- 파싱·초기화·렌더링·오류 처리 코드 분리

## 기술

C, MiniLibX, Linux/X11, Make, DDA 레이캐스팅, 파일 파싱

## 빌드와 실행

Linux의 C 컴파일러와 Make, X11/Xext 및 BSD 개발 라이브러리, 그래픽 표시 환경이 필요합니다. `minilibx-linux` 디렉터리에 MiniLibX 소스가 준비되어 있어야 합니다. 해당 디렉터리가 비어 있으면 의존성을 먼저 준비하세요.

```sh
make
./cub3d map/validmap1.cub
```

저장소 이름과 실행 파일 이름은 다릅니다. 기존 Makefile의 실행 파일 이름 `cub3d`를 유지합니다. 지도에서 참조하는 텍스처 상대 경로가 유지되도록 저장소 루트에서 실행합니다.

## 코드 안내

| 경로 | 내용 |
| --- | --- |
| `src/render/dda.c` | 광선 방향, 격자 탐색, 벽까지의 거리 계산 |
| `src/render/` | 화면 렌더링 및 이동 처리 |
| `src/parse/` | 입력 파일과 지도 유효성 검사 |
| `src/init/` | 지도·그래픽 초기화 |
| `map/` | 정상 지도와 비정상 입력 예시 |

## 범위와 기여

범용 3D 엔진이 아닌 격자 지도 기반 레이캐스팅 구현입니다. 여러 작성자의 코드가 포함된 공동 학습 프로젝트이며, 파일별 작성자 표기와 커밋 이력을 유지합니다. 포함된 지도 예시는 자동 테스트 통과를 의미하지 않습니다. 이 문서는 소스 구조를 기준으로 작성했으며 실행 환경별 빌드·동작 검증은 별도입니다.
